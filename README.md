# 意大利语入门课本 · Primo libro di italiano

Corso di italiano per madrelingua cinesi: 16 lezioni con dialoghi da ascoltare, esercizi corretti in automatico, flashcard e glossario.

Il sito è un unico file statico (`index.html`) pubblicato con GitHub Pages: nessuna dipendenza, nessun server.
L'audio è pre-registrato in `audio/` con la voce femminile «Sara» (`if_sara`) del modello open source Kokoro-82M (Apache-2.0).
Ogni file si chiama come l'hash cyrb53 del testo normalizzato (vedi `akey()` in `index.html`). Se un file manca, il sito usa la sintesi vocale del dispositivo.
I progressi restano nel browser.
